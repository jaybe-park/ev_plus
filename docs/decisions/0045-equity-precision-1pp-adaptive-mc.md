# 0045. 에퀴티 정밀도 목표 ±1%p(1σ) — vs 랜덤·레인지 반영 모두 적응형 MC(500~2,500샘플), easy만 고정 40

- 상태: 유효
- 날짜: 2026-09-26 · 결정자: jaybe-park
- 대체: [0034](0034-abolish-equity-cache.md)의 정밀도 부분(±0.5%p, "약 1,000~2,000샘플"), [0014](0014-difficulty-is-mc-resolution.md)의 수치 부분(medium 300 / hard 1,200 샘플, "hard만 리버 1:1 전수")

## 맥락
ADR 0034는 봇·패널 에퀴티의 정밀도 목표를 표준오차 ±0.5%p(1σ)로 정하면서 "샘플 수는 약 1,000~2,000"이라고 적었다.
샘플 1개의 지분(승 1, 패 0, k인 스플릿 1/k)의 분산은 최대 0.25(p=0.5)라, 1σ ≤ 0.5%p에는 최대 10,000샘플이 필요하다. 1,000샘플이면 1σ ≈ 1.6%p다.
T-036 첫 구현은 ±0.5%p를 지키는 적응형 MC(1,000~10,000샘플)였고, 측정해 보니 medium·hard 판단 1회가 60~100ms, 에퀴티 패널 1회가 최대 약 0.3초였다(캐시 시절 2.5~9ms, 67ms).
응답 지연 때문에 목표를 완화했다.

## 결정
- 봇·패널 에퀴티의 정밀도 목표는 **표준오차 ±1%p(1σ)**다. vs 랜덤(`smart_equity`)과 레인지 반영(`ranged_equity`, hard 봇·패널 vs_range·상대별 1:1) 모두에 적용한다.
- 방식은 **적응형 MC**다. 250샘플씩 돌며 500샘플 이후 표준오차 `sqrt(표본분산/n)`이 1%p 이하가 되면 멈추고, 2,500샘플에서 끝낸다. 지분 분산 ≤ 0.25이므로 2,500이면 어떤 스팟도 목표를 만족한다(상한 자체가 보장).
  - 최소 500샘플: 표본분산 추정의 상대오차가 약 3%라 조기 종료 판정이 믿을 만하다. 에퀴티가 극단적인 스팟(p=0.95 → 필요 약 475)도 여기서 끝난다.
- 난이도: easy만 고정 40샘플(ADR 0014 "난이도 = 해상도", 0034의 easy 예외). medium·hard는 적응형. 리버 1:1 전수·프리플랍 상수 테이블은 모든 난이도가 쓴다(0034).

## 버린 대안
- ±0.5%p 유지(적응형 1,000~10,000샘플) — 판단 60~100ms, 패널 최대 약 0.3초로 느리다.
- 봇과 패널의 목표를 다르게(이원화) — 같은 스팟에서 봇과 화면이 다른 해상도의 값을 보게 되고, 설정·설명할 것이 늘어난다.
- 고정 1,000~2,000샘플 — 1σ가 1.1~1.6%p라 p≈0.5 스팟에서 목표를 어긴다. 적응형은 목표를 보장하면서 에퀴티가 한쪽으로 치우친 스팟에서 샘플을 아낀다.
