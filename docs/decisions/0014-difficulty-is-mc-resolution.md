# 0014. 봇 난이도 = MC 샘플 수(판단 해상도), 일부러 약하게 코딩하지 않는다

- 상태: 일부 대체됨 → [0045](0045-equity-precision-1pp-adaptive-mc.md) (샘플 수치·"hard만 리버 전수". "난이도 = 해상도, 일부러 약하게 코딩하지 않는다" 원칙은 유효)
- 날짜: 2026-07-07 · 결정자: jaybe-park

## 맥락
봇을 equity 기반으로 다시 쓰면서 easy/medium/hard를 어떻게 구분할지 정해야 했다. "가끔 일부러 틀린 액션을 고른다" 같은 규칙은 부자연스럽고, 튜닝할 손잡이가 많아지며, 난이도끼리 전략이 달라져 아레나 비교가 어려워진다.

## 결정
난이도의 핵심 축은 **포스트플랍 equity 추정의 해상도**다. 모든 난이도가 같은 의사결정 로직을 쓰고, MC 샘플 수(easy 40 / medium 300 / hard 1200)가 다르다. 샘플이 적으면 추정 오차(easy 약 ±8%) 때문에 자연스럽게 실수한다. hard는 여기에 리버 1:1 전수조사와 프리플랍 액션 기반 상대 레인지 반영을 더한다. 프리플랍은 GTO 준수율(easy 40% / medium 70% / hard 95%)로 구분한다. 콜 마진·블러프 빈도 같은 성향 수치는 난이도 프로파일에 함께 두지만, "바보 짓" 규칙은 두지 않는다.

## 버린 대안
- 난이도별로 다른 전략 코드 / 일부러 실수하는 확률 규칙 — 부자연스럽고, 아레나에서 무엇이 좋아졌는지 분리하기 어렵다.
