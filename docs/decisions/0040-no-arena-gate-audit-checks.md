# 0040. GTO 수집 뒤 아레나 게이트는 되살리지 않고 audit 무결성 검사로 대신한다

- 상태: 유효
- 날짜: 2026-09-26 · 결정자: 에이전트(추천안, 사용자 위임)

## 맥락
ADR 0013은 "audit + 테스트가 나쁜 데이터 유입을 막는다"는 전제로 아레나 bb/100 게이트를 폐기했다. 2026-09-26 리뷰에서 그 전제가 성립하지 않았음이 드러났다(저장·워커 경로 테스트 0개, audit은 노드 덮어쓰기를 못 잡음). 이후 원칙 테스트가 43개 이상 생겼다.

## 결정
아레나 게이트는 되살리지 않는다. 대신 `scripts/audit_gto_preflop.py`에 두 가지 무결성 검사를 추가한다.
- "행의 3종 키 = derive_node_meta(action_seq)"
- "체크포인트 visited 결정 노드인데 DB·failed에 없음 = 0"

## 버린 대안
- 수집 후 아레나 bb/100 게이트 — 데이터 오염은 bb/100 노이즈(±10~20)에 묻혀 잘 안 잡히고, 매 수집마다 비용이 크다.
