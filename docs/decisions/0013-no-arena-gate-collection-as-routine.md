# 0013. 아레나 검증 게이트 폐기, 수집은 운영 루틴

- 상태: 유효
- 날짜: 2026-07-17 · 결정자: jaybe-park

## 맥락
원래 계획은 "파일럿 수집 → 아레나 bb/100으로 개선 확인 → 개선 없으면 롤백" 후 확장하는 순서였다. 그런데 사용자가 실제 플레이로 체감 개선을 이미 확인했고, 수집 결과 수치는 매번 바뀌므로 TODO에 목표치로 박아 두면 곧 낡는다.

## 결정
"아레나 bb/100 검증 게이트" Task를 폐지한다. 데이터 기반 트리 수집(`scripts/collect_gto_tree.py`)은 더 이상 별도 관리 Task가 아니라 상시 운영 루틴으로 돌린다("퇴근 시 돌려놓기"에서 선택적으로 실행). 수집 현황은 `scripts/gto_tree_report.py`가 `docs/gto-preflop-progress.md`를 자동 생성하는 것으로 갈음하고, 이 문서는 수동 편집하지 않으며 데이터 기반 원칙상 전체 규모를 모르므로 "전체 대비 %"는 표시하지 않는다.

## 버린 대안
- 파일럿 수집 → 아레나 bb/100 검증 → 확장 또는 롤백(원래 설계) — 실익이 없다고 판단했다.

## 결과
- 영향받는 spec: `docs/spec/gto-preflop.md`
- 강제 장치: `scripts/audit_gto_preflop.py`(수동 실행) — `tests/run_all.py`에는 포함되지 않는다.
- 이 결정의 전제("audit + 테스트가 나쁜 데이터 유입을 막는 게이트가 있으니 별도 검증 게이트가 필요 없다")는 현재 성립하지 않는다: 저장·워커 경로에는 테스트가 없고, audit 스크립트도 노드 덮어쓰기 같은 문제를 잡지 못한다 — DECISIONS.md 참고.
