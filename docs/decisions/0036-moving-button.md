# 0036. 파산으로 좌석이 빠질 때는 무빙 버튼

- 상태: 유효
- 날짜: 2026-09-26 · 결정자: jaybe-park

## 맥락
봇이 파산하면 테이블에서 빠진다. 버튼을 플레이어 리스트의 인덱스로만 기억해서, 버튼 앞 좌석이 빠지면 버튼이 한 칸 더 건너뛴다. 직전 BB가 SB를 건너뛰고 바로 BTN이 되는 식이고, 리뷰 재현에서 파산 전환 119회 중 20회 발생했다. 좌석이 빠질 때의 버튼 규칙이 정해져 있지 않았다.

## 결정
무빙 버튼 규칙을 쓴다.
- 버튼은 매 핸드 "지금 살아 있는 플레이어 중 직전 버튼 보유자의 다음 사람"으로 옮긴다.
- SB·BB는 그 뒤 두 명이다(헤즈업은 버튼 = SB).
- 버튼 보유자는 인덱스가 아니라 플레이어(이름 또는 고정 좌석)로 기억한다.
- 딜러 이동은 다음 핸드 시작 시점에 한다. 그래서 핸드 종료 응답의 포지션은 방금 친 핸드 기준이다.

## 버린 대안
- 데드 버튼(정식 카지노 규칙) — 블라인드 공정성은 완벽하지만, 빈 좌석 추적·SB 없는 핸드·화면 표시까지 필요해 비용이 크다. 혼자 봇과 치는 연습용에는 과하다.
