# 0002. GTO Wizard 값은 화면 그대로만 저장(추측·보간 금지)

- 상태: 유효
- 날짜: 2026-07-10 · 결정자: jaybe-park

## 맥락
추출 스크립트의 RGB 임계값 버그로 call이 100% 유실됐고 allin도 불안정하게 잡혔다. DB 전수 검증 결과 call>0인 행이 8,619개 중 0개였다. 봇 프리플랍 판단, hard 봇 콜 레인지, 플레이 평가가 모두 이 오염된 데이터를 기준으로 돌고 있었다. `raise_size`도 "3x" 같은 실측이 아닌 값이었다.

## 결정
GTO Wizard 값은 화면에서 읽은 그대로만 저장한다. 계산·추측·보간은 금지한다. 저장 전에 핸드별 빈도합이 [0.9, 1.1] 안에 있는지 검증하고(badSum 게이트), 실패한 스팟은 저장하지 않고 "손상/미수집" 상태로 둔다. 로더도 합이 범위 밖인 핸드는 건너뛰어 `None`을 반환하고(휴리스틱 폴백으로 넘김), 잔여 빈도를 fold로 채우지 않는다. 손상/누락 핸드를 fold로 채우지 않는 원칙은 이후 미수집 노드 전반(0009, 0010)에도 그대로 적용된다.

## 버린 대안
- 잔여 빈도를 fold에 몰아주는 보정 — 틀린 데이터를 그럴듯하게 숨긴다.
- 손상 데이터 부분 교정 — 근본 원인이 파서라 전량 무효화 후 재수집을 택했다.
