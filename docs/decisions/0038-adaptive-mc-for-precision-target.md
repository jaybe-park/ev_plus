# 0038. 정밀도 목표 ±0.5%p는 적응형 MC로 지킨다 — 샘플 1,000~10,000, easy만 고정 40

- 상태: 유효 (사용자 확인 대기 — 응답 시간 증가)
- 날짜: 2026-09-26 · 결정자: 구현 에이전트(T-036), ADR 0034 이행
- 대체: [0014](0014-difficulty-is-mc-resolution.md)의 수치 부분(medium 300 / hard 1200 샘플, "hard만 리버 1:1 전수")

## 맥락
ADR 0034는 봇·패널 에퀴티의 정밀도 목표를 표준오차 ±0.5%p(1σ)로 정하면서 "샘플 수는 상대 수에 따라 약 1,000~2,000"이라고 적었다.
그런데 샘플 1개의 지분(승 1, 패 0, k인 스플릿 1/k)의 분산은 최대 0.25(p=0.5)라, 1σ ≤ 0.5%p에는 최대 0.25 / 0.005² = 10,000샘플이 필요하다. 1,000샘플이면 1σ ≈ 1.6%p다.
두 문장이 동시에 참일 수 없어, 규범인 정밀도 목표를 따르고 샘플 수를 목표에서 다시 정했다.

## 결정
- vs 랜덤 에퀴티의 MC는 **적응형**이다. 500샘플씩 돌며 1,000샘플 이후 표준오차 `sqrt(표본분산/n)`이 0.5%p 이하가 되면 멈추고, 10,000샘플에서 끝낸다(10,000이면 어떤 스팟도 목표를 만족).
- 난이도: easy만 고정 40샘플(ADR 0014 "난이도 = 해상도", 0034의 easy 예외). medium·hard는 적응형. 리버 1:1 전수·프리플랍 상수 테이블은 모든 난이도가 쓴다(0034).
- 레인지 반영 에퀴티(`ranged_equity`, hard 1,200·패널 1,000샘플)는 이번에 바꾸지 않는다 — 캐시와 무관한 경로이고, 적응형으로 바꾸면 패널 응답이 더 늘어난다. 적용 여부는 별도로 정한다.

## 버린 대안
- 고정 1,000~2,000샘플(0034 문구 그대로) — 빠르지만(판단당 약 7~15ms) 1σ가 1.1~1.6%p로 목표를 어긴다.
- 고정 10,000샘플 — 목표는 지키지만 p가 극단적인 스팟(에퀴티 90% 등)에서도 최대 비용을 낸다. 적응형은 같은 보장에 평균 샘플이 적다(실측 플랍 vs5 평균 약 4,800).

## 결과
- 영향받는 spec: `docs/spec/equity.md`, `docs/spec/bot.md`
- 강제 장치: `tests/test_equity.py::test_mc_precision`(같은 스팟 반복 표준편차가 목표 이내, easy 40은 목표보다 거침)
- 잃는 것: 응답 시간. medium·hard 판단 1회가 2.5~9ms → 약 60~100ms, 패널 1회가 최대 약 0.3초(상대 5명 플랍)가 됐다(`scripts/bench_equity.py`). 아레나 처리량도 줄었다. 체감상 문제가 되면 목표(±0.5%p)를 완화하거나 평가기를 빠르게 하는(ADR 0018의 룩업 평가기·numpy) 쪽을 사람이 정한다.
