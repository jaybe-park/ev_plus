# 0043. 새로고침하면 진행 중인 게임을 이어간다(서버 재시작은 복구하지 않음)

- 상태: 유효
- 날짜: 2026-09-26 · 결정자: 에이전트(추천안, 사용자 위임)

## 맥락
게임 상태는 서버 메모리에만 있고 브라우저는 세션 번호를 React 상태로만 들고 있어서, 새로고침이나 탭을 닫는 순간 게임에 돌아갈 방법이 없었다. 서버 재시작(개발 모드 자동 재시작 포함)은 게임 자체를 지운다.

## 결정
- 브라우저는 세션 번호를 `sessionStorage`에 보관한다.
- 페이지를 열 때 `GET /game/{id}/state`로 서버에 게임이 살아 있으면 이어간다.
- 서버 재시작 뒤에는 복구하지 않고 "세션 만료 — 새 게임" 안내를 띄운다.

## 버린 대안
- 서버 재시작까지 복구(게임 상태 파일 저장) — 저장 형식·버전 호환 비용이 크다. 재시작은 주로 서버 코드가 바뀔 때라 새 게임이 오히려 깔끔하다.
- 복구 안 함 — 가장 흔한 실수(새로고침)를 방치한다.
