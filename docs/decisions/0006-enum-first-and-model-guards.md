# 0006. enum 경로 우선·시퀀스 폴백 병렬 공존 + 데이터 모델 밖 가드

- 상태: 유효
- 날짜: 2026-07-10, 2026-07-15 · 결정자: jaybe-park

## 맥락
시퀀스 기반 조회(`action_seq`)로 전환하는 중에도 기존 봇·테스트를 깨지 않아야 했다. 한편 미수집 큐에는 우리 데이터 모델이 애초에 지원하지 않는 상황이 세 차례 같은 계열로 쌓였다: BB RFI 오판, vs_3bet에서 오프너가 아닌 사람("CO vs CO 3bet"), 림프 후 아이솔레이트(opener_pos=BB).

## 결정
advisor는 enum 3종 키(position/vs_position/range_type) 조회를 먼저 시도하고, 없으면 시퀀스 키 조회로 폴백한다. 동시에 advisor는 우리 데이터 모델이 지원하는 상황만 조회하고 큐에 기록한다 — RFI는 BB를 제외하고, vs_3bet은 `my_position == opener`인 경우만, vs_open은 오프너가 나보다 앞 좌석인 경우만 다룬다. 그 밖의 상황은 조회도 큐 기록도 하지 않고 `None`을 반환해 휴리스틱으로 넘긴다.

## 버린 대안
- 시퀀스 경로로 일괄 전환 — 전환 도중 기존 봇·테스트 동작을 깰 위험이 있었다.
- 모델 밖 상황도 모두 큐에 기록하고 사람이 정리 — 오탐 53건이 쌓였다.
