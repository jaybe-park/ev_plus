# 0031. 봇 전용 핸드는 아카이브 후 삭제, 사람 참여 핸드는 영구 보존

- 상태: 유효 (아레나 미기록([0051](0051-drop-rl-columns-arena-not-recorded.md))으로 분류가 맞게 됨)
- 날짜: 2026-07-08 (사용자 지적으로 최초 삭제안을 수정) · 결정자: jaybe-park

## 맥락
`poker.db`가 계속 커지는 상황에서 오래된 핸드 기록을 정리할 방법을 검토했다. 최초안은 N일 경과 핸드를 단순 삭제하는 것이었다.

## 결정
셀프플레이(봇 전용) 핸드는 RL 학습의 주 데이터이므로 그냥 삭제하지 않는다. N일이 지난 봇 전용 핸드는 Parquet/JSONL.gz로 내보낸 뒤 DB에서만 제거한다(파일로는 남는다). 사람이 참여한 핸드는 삭제·아카이브 대상에서 제외하고 DB에 영구 보존한다. 어느 핸드가 "봇 전용"인지 구분하려면 `bot_version` 컬럼이 선행 조건이다.

## 버린 대안
- 오래된 핸드를 조건 없이 삭제 — 셀프플레이 데이터가 RL 학습의 주 자원이라 손실이 크다.

## 결과
- 영향받는 spec: `docs/spec/db.md`
- 강제 장치: 없음. 아카이브 자체가 아직 구현되지 않았다(선행 조건인 `bot_version` 컬럼 포함 진행 여부는 DECISIONS D-14).
