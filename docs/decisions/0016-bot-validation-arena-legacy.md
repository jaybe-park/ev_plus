# 0016. 봇 검증 = 아레나 bb/100 + legacy 베이스라인, 튜닝 결과는 사람이 반영

- 상태: 유효
- 날짜: 2026-07-07 · 결정자: jaybe-park

## 맥락
봇 로직을 바꿨을 때 "좋아졌다"를 판단할 수단이 없었다. 포커는 분산이 커서 몇 판 두어 보는 것으로는 알 수 없고, 단위 테스트로는 실력을 측정할 수 없다.

## 결정
봇끼리 같은 테이블에서 대전시키는 아레나(`scripts/bot_arena.py`)로 bb/100을 비교한다. 매 핸드 스택을 100bb로 리셋하고, 딜러 로테이션으로 포지션 유불리를 상쇄한다. 기준점으로 개선 전 핸드랭크 휴리스틱 봇을 `legacy` 프로파일로 아레나 스크립트 안에 보존한다(프리플랍 GTO는 같고 포스트플랍만 옛 방식). 로직 변경 후에는 `scripts/ai_regression.py`(고정 좌석·고정 시드)로 legacy보다 약해지지 않았는지 확인한다. ±10~20 bb/100 이내 차이는 노이즈로 보고 핸드 수를 늘린다. 파라미터 튜닝(`scripts/tune_bot.py`)은 결과를 `tuning_results.json`에 쌓기만 하고, 봇 코드 반영은 사람이 확인 후 수동으로 한다. 아레나는 매 핸드 칩 총량 보존을 assert해 엔진 퍼징도 겸한다.

## 버린 대안
- 튜닝 결과 자동 반영 — 분산 때문에 우연한 승자가 코드에 박힐 수 있다.
- 베이스라인 없이 난이도끼리만 비교 — 전체가 함께 나빠져도 알 수 없다.

## 결과
- 영향받는 spec: `docs/spec/bot.md`
- 강제 장치: `scripts/ai_regression.py`(legacy보다 약하면 exit 1) — 수동 실행, `tests/run_all.py`에 없음. 칩 보존 assert는 `scripts/bot_arena.py` 안(위반 시 `chip_violations.log`).
- 채택 기준(몇 핸드·몇 시드·얼마 차이)은 아직 정해지지 않았다 — DECISIONS.md D-20.
